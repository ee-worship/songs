# Песни прославления

Закрытый сайт команды: песни на русском и иврите с аккордами, транскрипцией, сет-листами и проектором.

- **Сайт** — `index.html` (GitHub Pages). Песен в нём нет: они приходят из базы и только участникам команды.
- **База** — Supabase. Войти можно только по ссылке-приглашению; админ управляет командой и удалением песен.
- **Схема базы** — `supabase/` (коды приглашений и токен резервной копии хранятся только в базе).
- **Исходники** — `src/`: `app_template.html` (приложение), `cloud.js` (работа с базой), `pdf_import.js` (импорт PDF и скриншотов), `build_site.py` (сборка).
- **Резервные копии** — в отдельном приватном репозитории.

Сборка:

```
CLOUD_URL=https://<проект>.supabase.co CLOUD_KEY=<publishable key> python3 src/build_site.py songs.json index.html
```
